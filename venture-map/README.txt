창업 단계 지도 (로컬 실행)

1. Node.js 설치 (https://nodejs.org, LTS 버전). 이미 있으면 생략.
2. 이 폴더를 압축 해제.
3. 터미널(Windows는 PowerShell, Mac은 터미널)을 열고 그 폴더로 이동:
     cd 압축푼폴더경로
4. 실행:
     node server.js
5. 브라우저에서 http://localhost:3000 열기.

데이터는 data/projects/*.json 에 저장됩니다. (이 폴더만 백업하면 됩니다)
- template.json : 빈 템플릿 (6단계 + 졸업 조건)
- sticker-workshop.json : 지금 하는 프로젝트 예시
화면의 "템플릿에서 새로 만들기"로 새 프로젝트를 만들고, "이 프로젝트 복제"로 복사합니다.
이 컴퓨터에서만 열립니다 (127.0.0.1). 폰이나 다른 사람과 쓰려면 나중에 클라우드로 옮겨야 합니다.
